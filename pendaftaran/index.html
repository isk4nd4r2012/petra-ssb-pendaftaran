Pernyataan & Tanda Tangan

Isi resmi dari 3 dokumen persyaratan PSSI. Baca ringkasannya lalu centang jika setuju.

1. Persetujuan Data Pribadi

Dengan mencentang ini, saya menyatakan:
  • Bersedia memberikan data pribadi & dokumen sesuai regulasi PSSI.
  • PSSI akan menggunakan data ini untuk registrasi stakeholder sepak bola di Indonesia.
  • Data dapat diteruskan ke PT Liga Indonesia Baru, AFF, AFC, dan FIFA untuk keperluan registrasi.
  • Hak saya sebagai subjek data dijamin sesuai UU Perlindungan Data Pribadi No. 27/2022.
  • Data yang saya berikan adalah sah, terkini, dan benar.
  • Saya dapat menghubungi PSSI bila ingin mengubah persetujuan ini di kemudian hari.

2. Surat Pernyataan Pemain

Sebagai orang tua/wali, saya menyatakan bahwa anak saya belum pernah bergabung dengan klub anggota/calon anggota PSSI lain maupun klub dari luar Indonesia.

3. Perjanjian Amatir

Saya mengizinkan anak saya mendaftar dan menjadi anggota SSB PETRA SENTANI dengan status "Pemain Amatir", serta bersedia memenuhi dan mematuhi seluruh peraturan yang berlaku di SSB PETRA SENTANI.
